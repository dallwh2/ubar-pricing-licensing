**uBar 和系统自带的 Dock 能同时用吗？**
可以。uBar 支持把系统 Dock 隐藏起来，也可以只让它出现在某一块屏幕上。

**uBar 和 Dock 冲突吗？**
不冲突。它替代的是 Dock 的显示位置，系统本身的窗口管理逻辑不变。
